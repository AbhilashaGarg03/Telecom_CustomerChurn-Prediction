# Contributing to Telecom Customer Churn Prediction

Thank you for your interest in contributing to this project!

## How to Contribute

### Reporting Issues
- Clearly describe any issues
- Include data samples if relevant
- Specify model performance impact

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Install dependencies: `pip install -r requirements.txt`
4. Make your improvements
5. Test model performance thoroughly
6. Push and submit a Pull Request

## Code Guidelines

- Follow PEP 8 conventions
- Document model changes
- Include performance metrics
- Add clear comments

## Areas for Contribution

- Improving churn prediction accuracy
- New feature engineering
- Better customer segmentation
- Enhanced visualizations
- Performance optimization
- Documentation improvements

## Pull Request Process

1. Validate model performance
2. Include performance comparison
3. Update README if needed
4. Provide clear descriptions

Thank you for contributing! 🙏
